# Rollin Documentation

Rollin is a mobile application that helps college students discover activities, connect with other students at their university, and coordinate rides for low to no cost.

This documentation explains how the major features work, the decisions that were made during development, and technical challenges we faced during development.

## Purpose

This documentation is written by developers for developers who want to understand, maintain, or continue building Rollin.

## Main Features

The main features of the Rollin application so far are as follows:

- Authentication
- Password recovery
- User profiles and connections
- Activity creation and discovery
- Messaging and notifications
- Ride sharing
- Live ride tracking
