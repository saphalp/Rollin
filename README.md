# Rollin

Rollin helps college students find activities, meet other students, and share rides for little or no cost. It includes activity hosting, campus events, messaging, a calendar, and ride coordination.

## Try the app

The Android demo/test build uses the package name `com.rollin.app`. Open the [Play Store link](https://play.google.com/store/apps/details?id=com.rollin.app). If it is not available to your Google account, ask the team for testing access and the current install link.

## Work on Rollin

Start with [Getting Started](docs/getting-started.md) for local setup. Feature branches merge into `dev` for testing; `main` is for production. See [Development Workflow](docs/development-workflow.md) before sharing changes.

The app uses React Native, Expo, TypeScript, and Supabase. The [documentation site](https://rollin.readthedocs.io/en/latest/) explains the features, setup, and development decisions. Its source pages are in `docs/`.
