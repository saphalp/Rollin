# User preference: never push

Never push commits, branches, or tags to any remote. The user handles all pushes.
Do not interpret requests to prepare working code, make something ready to push,
or have something available for standup as permission to push. Complete local
work and checks, then report the result and provide commands for the user when
requested. Do not undo a previous push or change remote branches without a
separate explicit instruction from the user.
